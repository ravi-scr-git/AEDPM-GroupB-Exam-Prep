## 📥 Download and Run Locally

### 1. Clone the Repository
```bash
git clone https://github.com/ravi-scr-git/AEDPM-GroupB-Exam-Prep.git
cd AEDPM-GroupB-Exam-Prep
```

### 2. Launch the Application
- **Windows One-Click:** Double-click `launch_app.bat` to launch the local server and open your default browser.
- **Python Local Server:**
  ```bash
  python server.py
  ```
  Open `http://localhost:8080/index.html`
- **100% Offline (Zero Server):** Just double-click `index.html` in Chrome, Edge, or Firefox!

## 🌟 Key Features

1. **📖 Detailed Topic Notes & Examples:**
   - Detailed coverage of all **47 topics** across Establishment, Financial, and Technical domains.
   - Statutory citations from **IREC Vols. I & II**, **IREM Vols. I & II**, **IRFC Vols. I & II**, **GCC 2022**, and standard university textbooks.
2. **🗺️ Interactive Memory Maps & Neat Design Flows:**
   - **OS Process Memory Map:** 32-bit/64-bit virtual address space layout (Text, Data, BSS, Heap, `mmap`, Stack, Kernel).
   - **Computer Memory Hierarchy:** Access latency, bandwidth, and capacity from CPU Registers (~0.5 ns) to LTO Tape.
   - **CRIS CONCERT (PRS) Enterprise Architecture:** Web gateways, F5 load balancers, application clusters, to in-memory Redis and Oracle RAC databases.
   - **Railway Servants (D&A) Rules Procedure Flow:** Dual-path flowchart comparing Minor Penalty (SF-11) vs Major Penalty (SF-5), IO, PO, and appeals.
   - **Works Programme & Capital Budget Lifecycle:** 6-stage lifecycle from surveys, Pink Book approval, to Completion Reports.
3. **⏱️ Official Group 'B' CBT Exam Simulator:**
   - Randomized **100-question mock tests** with a **120-minute countdown timer**.
   - Official Railway CBT scoring: **+1.0 Mark** for correct answers and **-1/3 (-0.33) Mark** deduction for incorrect answers.
   - Question Navigator Palette (Answered, Unanswered, Marked for Review) and score diagnostic review.
4. **⚡ Deprecated vs. Modern Technology Matrix:**
   - Evaluates legacy topics: **29 Labour Acts vs 4 Labour Codes 2020**, **Merged Railway Budget**, **OPS/NPS vs UPS 2024/2025**, **VB6/D2K vs Web Microservices**, and **Google+ Shutdown**.
5. **📇 Flashcard Revision Mode:**
   - Rapid-recall cards for instant revision of statutory rules, standard forms, and technical metrics.
